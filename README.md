# sdkviewer
Constantly updated cs2 offsets (faster than a2x)
### Goals
~~- 5 stars: release binary of the dumper~~ Under the Releases tab!
- 10 stars: auto offset searcher (it gives updated offsets based on the ones you gave it)
- 15 stars: auto schema and sdk dumpers. 
- 20 stars: release source of everything

> [!IMPORTANT]
> Schema generation is currently bugged.  (every offset is pointing to 0x20 or similar value)
> I have no way of fixing this at the moment, but it will be fixed in the near future.
> The schema still dumps all cs2 types that are used inside of the schema dumps so you're welcome of using those (they include padding aswell)
